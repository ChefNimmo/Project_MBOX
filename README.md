# Project MBOX

Research and early development for the original Digidesign Mbox (USB VID 0DBA, PID 1000) on Windows 11.

Status: protocol research and offline format-conversion prototype. No installable Windows driver yet. No hardware streaming tested.

See research/README.md for sources and windows/README.md for implementation status.

Proprietary demo installers and unlock keys are not redistributed in this repository.
